Atividade prática 2 - Interfaces
Tema: Meios de transporte

Compilação:
  javac *.java

Execução:
  java Main

Arquivos:
  MeioTransporte.java - contrato principal, método default, constante e método static
  Rastreavel.java - segunda interface do desafio opcional
  CarroParticular.java, Motocicleta.java, OnibusUrbano.java - três realizações iniciais
  BicicletaCompartilhada.java - quarta classe adicionada na extensão
  CentralDeTransportes.java - serviço que recebe a interface e vetor da interface
  Main.java - testes, polimorfismo e comentários sobre erros do compilador
  DiagramaTransportes.puml - diagrama de classes
